# 数据格式

看板读 `data/` 目录里的文件。只有 `universe.json` 是必需的；另外两组是可选的，没有时页面会跳过对应功能（本机服务对缺失的可选文件回 204，页面不会报错）。

## `data/universe.json`（必需）

股票名单，由 `python tools/update_universe.py` 生成。

```json
{
  "asOf": "2026-11-10",
  "industries": ["白酒Ⅱ", "银行Ⅱ", "..."],
  "stocks": [
    ["sh600519", "贵州茅台", 0, 3580000000],
    ["hk00700", "腾讯控股", 12, 15600000000],
    ["usAAPL", "苹果", 40, 54700000000]
  ]
}
```

- `stocks` 每一行：`[代码, 名称, 行业序号, 成交额]`。
  - 代码格式：`sh` / `sz` / `bj` + 6 位数字，`hk` + 5 位数字，`us` + 美股代码。
  - 行业序号指向 `industries`，同一行业的股票在星云上聚在一起。
  - 成交额按各自币种计，只用来决定光点大小，页面会用实时成交额覆盖。
- 行的顺序就是星云里股票的顺序；`history.bin` 的行序必须和它一致。

## `data/history.json` + `data/history.bin`（可选：收盘后回放、因子 IC）

所有市场都收盘后，页面按天回放近期全市场的真实涨跌，并用它算“因子”面板里的 Rank IC。

`history.json`：

```json
{
  "days": ["2026-08-03", "2026-08-04", "..."],
  "rows": 8564,
  "cols": 60,
  "indices": {
    "sh000300": { "close": [3900.1, 3912.4], "prev": [3890.0, 3900.1] },
    "hkHSI":    { "close": [], "prev": [] },
    "usINX":    { "close": [], "prev": [] }
  },
  "dayAmount": [1.21e12, 1.33e12]
}
```

- `days`：交易日，从早到晚，长度等于 `cols`。
- `rows`：必须等于 `universe.json` 里的股票数，不相等时页面不回放。
- `indices`：基准指数每天的收盘价和前收盘价（和 `days` 对齐），回放时顶部指数、波动漏斗用。可以只给其中几个。
- `dayAmount`：A 股每天的总成交额（元），可省略。

`history.bin`：`rows × cols` 个 16 位有符号整数（小端），按行排列，第 `i` 只股票第 `k` 天在下标 `i * cols + k`。

- 值是当天涨跌幅乘以 100（`+2.35%` 存 `235`），缺失或停牌存 `-32768`。
- 能表示的范围是 ±327%，超过的请截到 ±320%（页面把 ±320% 当成封顶值，不上涨跌榜）。

## `data/rules.json`（可选：规则信号、回测）

你自己的选股规则算出来的结果。页面只负责展示：每套规则今天符合条件的股票、回测净值、到期跟踪。

```json
{
  "asOf": "2026-11-07",
  "rules": [
    {
      "id": "MY_RULE",
      "title": "规则名",
      "tagline": "一句话说明",
      "summary": "规则的完整说明",
      "poolSize": 3200,
      "hits": [
        {
          "code": "sh600519", "name": "贵州茅台", "stars": 4,
          "headline": [["市盈率", "22.0"], ["近 20 日", "+3.1%"]],
          "checks": [["市盈率低于 30", true, "22.0"], ["站上 60 日线", false, "差 1.2%"]]
        }
      ],
      "backtests": {
        "A": {
          "start": "2024-01-02", "end": "2026-11-07", "periods": 34,
          "ruleReturn": 0.31, "benchmarkReturn": 0.12,
          "maxDrawdown": 0.18, "benchmarkMaxDrawdown": 0.22, "beat": 20,
          "daily": [["2024-01-02", 1.0]],
          "benchmarkDaily": [["2024-01-02", 1.0]],
          "events": [["2024-01-03", "buy", "sh600519", "贵州茅台", 100, 1650.0]],
          "buys": 170, "blockedBuys": 3, "delayedSells": 2, "costRatio": 0.012,
          "note": "每 21 个交易日换一次，等权持有 5 只；次日开盘成交，含佣金和印花税"
        }
      }
    }
  ],
  "tracking": [
    { "rule": "MY_RULE", "market": "A", "horizon": 5, "days": 12, "avgReturn": 0.004, "avgExcess": 0.002, "beatShare": 0.58 }
  ],
  "trackingSince": "2026-10-20"
}
```

- 必需字段：
  - 每套规则要有 `id`、`title`、`tagline`、`summary`、`poolSize`、`hits`。没有符合条件的股票时 `hits` 写空数组 `[]`；缺了这个字段，整份文件会被当成没有规则数据。
  - 每只符合条件的股票要有 `code`、`name`、`stars`、`headline`、`checks`。
  - 每份回测要有上面示例里除 `note` 以外的全部字段。
- `stars` 是 0 到 5 的整数，表示数据和规则条件的符合程度，不是涨跌预测。
- `relaxNote`（可选，写在规则上）：规则名下方的一行提示，例如条件临时放宽的说明。
- `backtests` 的键：`A`（A 股，对比沪深 300）、`HK`（港股，对比恒生）、`US`（美股，对比标普 500），没有的可以不写，这时可以给 `noBacktestReason` 说明原因。
- 收益、回撤都是小数（`0.31` 表示 31%）；净值序列从 1 开始。
- `note`（可选，写在回测上）：这份回测是怎么做的（换股周期、持仓数、成本口径等），页面原样显示在回测卡片下方；不写就不显示。
- `events` 是回测里的模拟成交：`[日期, "buy" | "sell", 代码, 名称, 股数, 价格]`，回放到那一天时显示。
